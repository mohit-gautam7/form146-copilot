# Visual design: what it borrows and why
**Brief.** A working tool for chartered accountants that also has to explain itself to reviewers in one screen. It must look trustworthy before it looks clever.
**Looked at.** Awwwards' 3D category, landing.love's 3D and finance categories, Ramp's design site, Dribbble and Webflow 3D tags, LottieFiles.
**Taken.** From Ramp: physical objects floating under soft studio light and tilting with the cursor, so the 3D shows the real artefacts of the work (a contract, an invoice, a treaty article, a certificate, a rubber seal) rather than abstract shapes. From the strongest Awwwards entries: one focal 3D moment, then calm photography and type. landing.love's line that depth should be "part of the argument rather than decoration" became the rule: the hero loop is the product's own sequence (models read, rules compute, CA seals) with a caption in step.
**Rejected.** Generic Lottie illustrations and stock 3D blobs: they would say "tech startup" instead of "tax certificate". Glassmorphism everywhere. Scroll-jacking: a CA should be able to skim.
**System.** Ledger-grey paper and blue-black ink. Three lane colours that carry meaning: violet for the AI, ledger green for the rules, seal red for the CA. Verbatim source text in a serif (Newsreader), everything else in Public Sans. Photographs (Unsplash, credited) of signing, a port at night, Mumbai, and a stamp on a tax file. Motion is reduced to a still, stamped frame when the reader asks for reduced motion.
**Tech.** three.js through React Three Fiber; the paper is drawn on a 2D canvas at runtime, so the scene loads no fonts or models from elsewhere and the 3D code is split out of the main bundle.
