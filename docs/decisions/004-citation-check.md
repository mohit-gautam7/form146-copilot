# 004 Quotes are checked as exact text, and a vote must be anchored
**Context.** Models invent plausible quotes. An auditor must be able to find every cited sentence in the source.
**Decision.** Every quote is checked as an exact match after normalising case, whitespace, curly quotes and Unicode hyphens. Legal-style elisions ("A ... B") are allowed only if each fragment is exact and in order. A vote counts only if at least one contract or invoice quote and at least one treaty quote are found. Any quote that is not found is shown to the CA in red and downgrades a unanimous result to "majority only".
**Revised after the first live run.** The original rule was stricter: one unfound quote voided the whole vote. On the first live run it threw away correct answers for transcription slips. One model wrote "non‑exclusive" with a non-breaking hyphen. Another joined two real treaty passages with "...". A third wrote "that make available" where the treaty says "which ... make available". None of these were fabrications. The revised rule still refuses paraphrase (a fragment must match exactly), but it no longer lets one slip silence an otherwise anchored answer. lib/citations.test.ts pins both behaviours.
**Trade-off.** A model can now pad a good answer with one invented quote and still be counted. The mitigation is visibility: the CA sees the red quote and the result cannot be "agree".
